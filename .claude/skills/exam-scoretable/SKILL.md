# 기출 시험 배점표 등록 절차

## 1. PDF 읽기
수식 폰트(PUA 문자) 때문에 텍스트 추출이 안 된다. 반드시 이미지로 렌더해서 눈으로 읽는다:
```bash
pdftoppm -png -r 150 시험지.pdf /tmp/exam
```
각 페이지에서 문항 번호 옆 배점 표기([4.6점] 등)를 판독한다. 서술형은 보통 뒤쪽에 몰려 있고 배점이 크다(10점 이상).

## 2. 키 규칙 (정확히)
```
gicul||<연도>||<학교>||<과목>||<학기>||<중간|기말>     (내신 기출)
mock||<연도>||<회차>                                    (모의고사)
mini||<연도>||<과목>||<N주차>                           (미니모의고사)
```
- 과목명은 **EXAM_SUBJECTS 기준** (공통수학1 / 공통수학2 / 대수 / 미적분Ⅰ[로마숫자] / 기하 / 확률과 통계 / 미적분Ⅱ)
- 학교명은 index.html의 SCHOOLS 목록에 있는 표기 그대로. 없으면 사용자에게 추가 여부 확인.

## 3. 등록 위치와 형식
index.html의 `seedExamScores` 함수 안, 기존 KEY들 뒤에 같은 패턴으로 추가:
```js
// <연도> <학교> <과목> <학기> <중간/기말> (<N>문항, 만점 <M> / 서술형 있으면 범위 표기)
var KEY##='gicul||...';
if(!tables[KEY##]){
  tables[KEY##]={ points:{ 1:3.3, 2:3.4, ... }, total:N, full:M };
  changed=true;
}
```
서술형 소문항 부분점수(B안)가 필요한 시험은 `points`를 `{17:{sub:[{label:"(1)",pt:3.0},{label:"(2)",pt:3.0}]}}` 형태로.

## 4. 검증 (필수 — 과거 0.4~0.7점 불일치 사고 있었음)
```python
pts = {...}  # 등록한 배점 그대로
assert abs(sum(문항별 배점 합) - full) < 0.01, "합계 ≠ 만점"
assert len(pts) == total
```
**합계가 만점과 다르면 등록하지 말고 어느 문항이 이상한지 사용자에게 보고한다.** 배점은 "3번 방식": PDF 원본 배점 저장, 만점 100 표시, 점수 = 100 − Σ틀린 문항 배점 (비율 환산 없음).

## 5. typeMap도 함께 요청받았으면
`data/기출_<과목>_통합_typeMap.json`의 `exams` 객체에 같은 키로 문항별 유형을 추가한다. 분류 규칙은 book-typemap 스킬의 분류 원칙과 동일 (문제+해설을 함께 읽고, 한 문항 = 대표 유형 1개, cat은 중단원 단위). 1번부터 마지막까지 누락 없어야 함 — Python으로 1~totalCount 전수 확인.
